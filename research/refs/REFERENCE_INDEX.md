# 参考图索引：2002 世界杯决赛版 R9（Ronaldo Nazário）

> 维护：01_appearance_2002 外观研究（详细分析见 `research/notes/01_appearance_2002.md`）。
> 时间范围：2002-06-24 至 2002-07-02。这段时间头发都是同一个 "Cascão" 造型：6/24 首次被拍到，6/26 半决赛，6/30 决赛，7/2 回到巴西利亚。
> 更早或更晚的图片单独列出，并标注年份。**不要用它们做发型参考。**

## 使用说明

- **视角约定**：「左 3/4 / 左侧面」指能看到**本人的左脸**，此时他的脸朝向画面左侧。「右 3/4 / 右侧面」反之。
  - 判断依据：本人**左耳**有耳钉孔，场外照片上常戴耳钉。
- **授权状态**：
  - **©**：版权新闻图（Getty Images / AFP / Bongarts / Popperfoto / EMPICS）。**不得放进仓库**，只能打开链接查看。
    - 研究时曾下载 612 px 带水印预览，放在会话临时目录 `…/scratchpad/refs_private/`，不随仓库交付。
  - **CC**：Wikimedia Commons 自由授权图，已下载到 `research/refs/commons/`，署名登记在 `ATTRIBUTION.jsonl`。
- **分级**：
  - 照片本身是一手影像证据（T1）。
  - 图注中的日期、地点来自通讯社（T2）。
  - "适用部位/备注"列是本组的观察判断（T4）。
- **视频**：所有 YouTube 视频都通过 oEmbed 核实过发布者。云端环境无法播放 YouTube（播放器 API 返回 `LOGIN_REQUIRED`，观看页返回 429）。
  - 因此**视频内的时间码一律未核**。表中给出的是比赛钟表时间（官方进球时间 67'、79'），实际时间码需要人工打开视频定位。
