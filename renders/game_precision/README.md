# 游戏精度预览（不是游戏截图）

由 `tools/wrap/game_precision.py` 生成（2026-10-25，最终模型）：

```
python3 tools/wrap/game_precision.py --blend model/source/r9_2002.blend --textures model/textures \
    --out-dir renders/game_precision --res 800 --samples 32 --parts R9_Head,R9_Eyes
```

- `hd_vs_game_sheet.png`：每行一个视角，三列分别是 高清 / LOD0 / LOD1。
- `renders/`：单张渲染；`tex_256/`、`tex_256_astc4x4/`：缩到 256 px 的贴图和 ASTC 4×4 往返后的解码图（渲染用的是解码图）。
- `game_precision_report.json`、`lod_stats.json`：顶点/三角数与贴图 PSNR。`lod*.blend` 不入库，可按上面的命令重建。

| | 头 + 眼（预算，参照亨利供体） | 头发壳（预算，假设） |
|---|---|---|
| LOD0 | 5,330 GPU 顶点（5,376），头未减面 | 1,592（1,600） |

贴图（256 px）：ASTC 4×4 相对未压缩 256 的 PSNR，头部反照率 59.9 dB、法线 54.8 dB、粗糙度 73.0 dB；256 放大回高清相对原图，反照率 41.7 dB。面部加权 UV 后，眉到下唇的五官区在 256 图上约 70×80 像素（目测；旧的单岛 UV 只有 54×44）。

## 如实说明

1. 这是**我们自己的网格用通用减面**得到的预览，用来回答"256 px 贴图和 5k/1.3k 顶点下还认不认得出"。真正进游戏的 LOD 是"包裹到原生供体拓扑"后的网格（`tools/wrap/wrap.py`），需要原始资源。
2. LOD1 颞部、外眼角附近和下颌下方的小暗斑/暗线是通用减面的伪影（推测是眼球等内层几何从减面后的皮肤里穿出，未逐一确认），不会出现在供体包裹路线中。旧发壳（极点朝上的射线网格）减面后头顶会出现一个小洞，换成均匀网格后已消失。
3. 牙齿和舌头不计入预算：高清版程序化牙齿上下各 6,832 顶点，放进同一预算会把头部 LOD1 压到 51 顶点。游戏里口腔来自供体头。
4. 头发假设是独立网格、单独预算，拿到原始资源后需要核对。
